## theextragg here 👋

I spend most of my time writing Rust and C, usually somewhere between the kernel and the terminal. I like understanding how things actually work underneath — memory layout, syscalls, the parts most people happily abstract away. Lately I've been drawn to WebAssembly as a compilation target and finding it a surprisingly interesting space to think about portability and constraints.
